## 🌸 О проекте

**femboygram** — клиентская версия шуточного мессенджера, который был максимально быстро написан ради эксперимента, веселья и проверки собственных навыков разработки.

Изначально это была просто идея сделать собственный мессенджер, но в итоге появился вполне рабочий клиент с графическим интерфейсом.

Не пытайтесь воспринимать его слишком серьёзно. Хотя... кто знает? 💅

## ✨ Возможности

- 💬 Обмен сообщениями
- 👤 Пользовательские аккаунты
- 🖼️ Аватарки и профили
- 🔐 Авторизация
- 🔒 Шифрование сообщений
- 🖥️ Графический интерфейс на Flet

*Функциональность может меняться по мере разработки.*

## 📦 Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/kavirodev/femboygram.git
cd femboygram
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

### 3. Активация

**Linux:**
```bash
source venv/bin/activate
```

**Windows:**
```powershell
venv\Scripts\activate
```

### 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 5. Запуск

```bash
python client_gui.py
```

## ⚠️ Важная информация

- Это экспериментальный проект, а не полноценный коммерческий мессенджер.
- Клиенту необходим работающий сервер femboygram. (Когда-нибудь его выложу...)
- Проект находится в разработке, поэтому возможны ошибки и нестабильная работа.
- Не используйте его для передачи действительно конфиденциальной информации.
